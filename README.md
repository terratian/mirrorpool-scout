# Mirror Pool Scout 🔮

**Mirror Pool Scout** is a high-efficiency Chrome extension built for Magic: The Gathering traders, competitive players, and procurement hunters. It transforms manual decklist sourcing into an automated, visual dashboard directly in your browser.

## Features
* **Live Market Procurement:** Injects a custom UI overlay into marketplace listings for one-click card tracking.
* **Intelligent Decklist Parsing:** Paste any MTG decklist to instantly generate a targeted, visual procurement grid.
* **Financial Tracking:** Monitor your market floor, total spent, and net variance in real time.
* **Data Sovereignty:** All watchlist and financial data is stored securely offline in your browser's local storage.

## Installation & Usage
1. Purchase and download the release ZIP from Gumroad.
2. Extract the downloaded ZIP file to your computer.
3. Open Chrome and navigate to `chrome://extensions/`.
4. Enable **Developer mode** in the top right corner.
5. Click **Load unpacked** and select the extracted `mirrorpool-scout` folder.
6. Click the Mirror Pool icon in your Chrome toolbar to open the Procurement Hunter dashboard!
