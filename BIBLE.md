# Mirror Pool Scout - Component Bible & Architecture Log

### Component: Bulk Cart Manifest Exporter
- **File:** `dashboard.js`
- **Purpose:** Aggregates unacquired inventory items from active deck registries (`deck.acquisitionState`) into a standard quantity-name text format.
- **Monetization Hook:** Designed to feed directly into mass-entry terminal endpoints wrapped with affiliate tracking parameters.

### Component: Subscription & Feature Gating Engine
- **File:** `dashboard.js`, `background.js`
- **Purpose:** Enforces a subscription validation check ($9.99/mo tier) before unlocking advanced procurement workflows like the Bulk Cart Manifest & Optimizer.
- **Licensing & Distribution:** Prepares the repository for clean proprietary licensing, GitHub repository hosting, and static landing page deployment.
